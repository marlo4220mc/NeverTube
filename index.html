Zero Electron Bloat

Pure C++17 and Qt5. Linux packages are around 1 MB, pulling shared distro libraries instead of embedding an entire Chromium runtime.

🎬

Dual Playback Engines

libmpv for Linux, Windows x64 and modern x86. Dedicated from-scratch FFmpeg/DXVA2 engine for legacy Windows 7 x86.

🔍

Hardware Probing

Automatically tests AV1, VP9 and H.264 decoders on startup, gracefully falling back to avoid CPU stalls.

📥

Parallel Downloader

Bypasses throttle ceilings using concurrent byte-range streams, muxing cleanly without re-encoding into MKV or MP3.

Get NeverTube

Choose your operating system or packaging format below.

Auto-Configured Signed Repository

Ubuntu 24.04 (noble) & 22.04 (jammy)

Download the .deb package from GitHub Releases. Installing it automatically imports the GPG signing key to /usr/share/keyrings/ and configures our official repository in /etc/apt/sources.list.d/nevertube.list so future updates arrive seamlessly via apt update. 

# Ubuntu 24.04 (or Ubuntu 22.04)
sudo apt install ./NeverTube-1.0.0-Ubuntu-24.04-amd64.deb
sudo apt update

Manual repo setup: https://marlo4220mc.github.io/NeverTube/apt/

Self-Updating Sandbox

Universal Linux (Silverblue, SteamOS, Arch, etc.)

Install with a single command via our signed .flatpakref. It adds the remote repository with our verified GPG key and installs the app. Future updates are applied with flatpak update. 

flatpak install --user https://marlo4220mc.github.io/NeverTube/flatpak/io.github.marlo4220mc.NeverTube.flatpakref
flatpak run io.github.marlo4220mc.NeverTube

Or download the single-file NeverTube-1.0.0-Linux-Flatpak.flatpak bundle. Installing it automatically adds the repository as well.

Dedicated Installers

Modern & Legacy Windows Support

NeverTube provides tailored installers for modern 64-bit/32-bit systems as well as dedicated Windows 7 SP1 builds.

  • Windows 10 / 11 (64-bit): NeverTube-1.0.0-Windows-10-11-x64-Setup.exe (libmpv engine, zero-copy support)
  • Windows 10 / 11 (32-bit): NeverTube-1.0.0-Windows-10-11-x86-Setup.exe (libmpv i686 engine)
  • Windows 7 SP1 (32-bit): NeverTube-1.0.0-Windows-7-SP1-x86-Setup.exe (dedicated FFmpeg/DXVA2 engine)

Native Packages

Fedora & Arch Linux

Native, lightweight packages built without bundled runtimes: 

# Fedora (.rpm)
sudo dnf install ./NeverTube-1.0.0-Fedora-x86_64.rpm

# Arch Linux (pacman)
sudo pacman -U NeverTube-1.0.0-Arch-Linux-x86_64.pkg.tar.zst
